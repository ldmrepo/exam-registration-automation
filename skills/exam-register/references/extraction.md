# 추출·분석 절차

[추출 역할](roles/extractor.md)에 따라 배정된 항목만 처리한다. manifest·assignment·queue 및 편집기는 변경하지 않는다.

## 배정 확인과 원본 읽기

마스터에게 받은 절대 작업 경로, 항목 ID, 명세 버전, 담당자, 대상 문서 ID를 확인한다. 이미지 크기와 명세의 크기가 다르거나 좌표가 경계를 벗어나면 마스터에게 반환한다. 파일을 임의 교체하거나 좌표를 원본 화면 크기에 맞춰 추측하지 않는다.

자신에게 배정된 별도 원본 탭 또는 로컬 이미지 열람 도구로 페이지를 읽는다. 다른 추출자의 탭·편집기 탭을 제어하지 않는다. 파일 기반 이미지 열람을 지원하면 공유 이미지 파일을 각자 읽는 것도 독립 환경이다. 브라우저 전용 PDF가 필요한 경우 각자의 원본 탭을 생성하고 탭 ID를 보고한다.

지정 영역뿐 아니라 전체 페이지를 확인한다. 문항 시작·끝, 인접 답항 혼입, 다중 영역의 읽기 순서를 대조한다. 영역 오류는 제안 좌표와 화면 근거를 마스터에게 보고하고 공식 명세 갱신을 기다린다. 그동안 다른 배정 항목을 처리할 수 있다.

## 편집 초안

- 발문·배점·조건 박스·참조기호·답항을 원문 순서로 작성한다. 지문 안내와 박스 헤더의 유무를 구분한다.
- 수식은 LaTeX 등 편집기의 편집 가능한 수식 입력으로 변환한다. OCR/PDF 문자열은 보조 자료이며 지수·분수·부등호·첨자·괄호를 시각 대조한다.
- 작은 지수 안의 부호처럼 축소 페이지에서 획이 뭉개지는 부분은 원본 PDF의 해당 영역을 더 높은 해상도로 렌더해 확인한다. 이미 축소된 이미지를 확대하는 것만으로 확정하지 않는다. 확대 근거의 경로와 대조 결과를 남긴다.
- 그림은 원본에서 잘라 확보한다. 축·점·주석·범례가 잘리지 않았는지 전체 원본과 함께 확인한다. 그림을 생성형 이미지로 다시 그리지 않는다.
- 그림의 원본 위치·크기·비율, 가운데 정렬 여부, 답항 열 수, 박스·표·대화체·옛한글 등 필요한 편집 특성을 기록한다. 옛한글은 편집기의 문자표에서 입력해야 할 문자와 원본 위치를 제공한다.
- 공식 정답 PDF의 학년도·과목·형·선택과목을 대조하고 해당 문항 답과 배점을 기록한다. 풀이로 추정한 답을 공식 정답으로 표시하지 않는다.

## 제출

`extracted/<item_id>/` 아래 새 버전으로 초안과 그림을 저장한다. 필드/제출 형식은 `scripts/parallel_run.py --help` 및 해당 하위 명령이 검사하는 규격을 따른다. 최소한 내용·수식·답항·정답 근거·그림 경로·서식·원본 위치·명세 버전·초안 버전·대조 결과·미해결 사항이 식별되어야 한다.

원본 대조 완료와 미해결 사항 없음이 확인되면 마스터에게 `EXTRACTED` 메시지로 산출물 경로와 버전을 제출한다. 대기열에 직접 넣지 않는다. 불확실한 문자는 추측하지 않고 `NEEDS_REVISION`으로 판독 위치·사유·필요한 자료를 보고한다.

제출한 버전은 덮어쓰지 않는다. 보완은 새 버전을 만들고 마스터에게 교체를 요청한다. 편집 중인 버전은 마스터가 편집 중단을 확인하기 전까지 변경 대상으로 취급하지 않는다.

## 제출 JSON

현재 CLI `ready`가 읽는 초안 예시다. source_regions는 명세의 regions 배열을 그대로 복사한다. version은 `assign`이 반환한 version이다. 예시 값이 아니라 실제 판독 내용과 근거를 기록한다.

```json
{
  "id": "q01", "version": 1,
  "source_checked": true, "unresolved": [],
  "html": "<p>실제 편집용 본문</p>",
  "source_regions": [{"image": "pages/questions-1.png", "image_size": [1432, 2025], "bbox": [70, 160, 610, 330], "page": 1, "printed_page": "1"}],
  "answer": "5", "answer_source": {"pdf": "source/answers.pdf", "page": 1, "item": "q01", "variant": "홀수형"},
  "assets": [], "format": {"choice_columns": 5},
  "comparison": {"boundary": "전체 페이지에서 시작·끝 확인", "math": "원본 수식과 대조"}
}
```

지문은 answer/answer_source 검사가 필요하지 않다. 그림은 `assets`에 작업 루트 기준 파일 경로를 빠짐없이 열거한다. html의 내용과 파일 경로·배치는 편집 담당이 실제 UI에서 재현할 수 있어야 한다. CLI는 제출 초안과 assets의 해시를 고정하지만 HTML 의미·공식 답의 정확성은 자동 판정하지 않으므로 대조 근거를 반드시 함께 제출한다.
