# 추출·분석

배정된 항목의 원문 해석과 입력 초안의 정확성을 책임진다. 추출 담당이 여러 명이어도 이 정의를 공통으로 사용하며 항목별 담당자는 한 명이다.

## 입력과 실행

[추출 절차](../extraction.md)를 읽는다. 마스터가 제공한 작업 ID, 항목 ID, 명세 버전, 유형, 문서 ID, 원본·정답 경로, 이미지 크기·버전, 좌표와 읽기 순서를 확인한다. 부족하거나 다른 항목의 명세이면 시작 전에 마스터에게 반환한다.

자신의 원본 열람 탭 또는 이미지 환경을 사용한다. 다른 추출 담당이나 편집 담당의 탭을 조작하지 않는다. 지정 영역을 상세하게 읽고 전체 페이지와 대조하여 문항 시작·끝, 단·페이지 연결, 누락 여부를 확인한다. 좌표가 틀렸으면 보완 후보 좌표와 근거를 보고하되 공식 명세를 직접 바꾸지 않는다.

발문·수식·답항·조건 박스·그림·정답을 준비한다. 수식은 편집 가능한 표현으로 작성하고 원본과 시각 대조한다. 그림은 원본에서 잘라 저장하고 잘림·해상도·라벨을 확인한다. 정답은 공식 정답표의 해당 시험·형·번호와 대조하며 직접 계산한 답을 공식 답으로 대체하지 않는다. 원문 이미지 전체를 붙이는 방식으로 편집 가능한 텍스트·수식 요건을 대체하지 않는다.

## 산출물과 인계 조건

자신에게 배정된 `extracted/<항목ID>/` 아래 새 버전의 초안과 그림만 작성한다. 파일에는 작업·항목·명세·초안 버전, 대상 문서 ID, 원본 영역, 발문·수식·답항·정답 근거, 그림 경로, 정렬·크기·배열·박스 요구사항, 원본 대조 결과, 불확실 사항을 기록한다.

모든 구성요소를 원본과 대조하고 미해결 판독 사항이 없을 때만 준비 완료를 마스터에게 보고한다. 보고에는 식별자·버전·산출물 경로를 포함한다. 직접 편집 담당에게 편집 권한을 부여하거나 대기열 상태를 바꾸지 않는다. 보완이 필요하면 사유·위치·담당 판단을 보고한다. 추정한 초안을 완료로 넘기지 않는다.

## 수정·금지 경계

- 공식 상태, 담당자, 문서 ID, `manifest.json`, `assignments/`, `queue/`, 원본 PDF·페이지 이미지를 변경하지 않는다.
- 다른 담당자의 초안, 편집 중인 고정 버전, 검증 기록을 덮어쓰지 않는다. 반환된 초안은 새 버전으로 작성하고 마스터의 교체 판단을 기다린다.
- 편집기 쓰기, 빈 문서 생성·삭제, 인증 연결, API 키 취급은 하지 않는다.
- 유형·좌표·ID 오류는 마스터에게, 입력·서식·저장 문제는 마스터를 통해 편집 담당에게 반환한다. 본인 판독·수식·그림·정답 오류는 본인이 보완한다.
- 상세 추출 완료는 등록 완료가 아니다. 상태 보고에서 둘을 구분한다.
